# 魔法字贪吃蛇 · Spellbound Snake

一款把经典贪吃蛇变成「边玩边写」奇幻旅程的网页游戏。蛇不吃食物，而吃散落在棋盘上的魔咒字——风、夜、梦、火、海、影……每吞下一个字，LLM 诗人续写一段只属于这局游戏的故事，图像生成模型即时切换整张棋盘的氛围。游戏结束时，你得到一篇由自己的选择塑造的奇幻短篇。

## 特性

### 核心玩法
- 蛇吃「魔咒字」而非食物，13 个字分属 8 大主题系
- 方向键 / WASD 控制方向，Space 暂停 / 继续，禁止 180° 反向
- 撞墙或撞到自身 → 游戏结束
- 吃字后蛇身变长，速度逐步加快，得分递增

### AI 双反馈
- **故事引擎**：吞下字时调用 LLM（z-ai-web-dev-sdk），以已收集的字、当前故事、是否共鸣为输入，续写 1-2 句诗意叙事，故事像河流般向前流淌
- **氛围图生成**：按字的主题调图像生成模型，返回氛围背景绘制到棋盘上，蛇身配色、粒子、光晕同步切换
- **服务端缓存**：同主题氛围图按 theme 内存缓存，二次命中秒切，不重复消耗 API

### 共鸣（Combo）机制
- 连续吃到同主题系字触发「共鸣」
- 共鸣时分数 ×2，蛇头发光，故事出现转折句
- 异主题字打断共鸣，鼓励有策略地选字

### 视觉分层
- **底层 Canvas**：AI 氛围背景 + 网格 + 咒文圆环（脉动呼吸）+ 蛇身（头→尾主题色渐变 + 朝向眼睛）
- **顶层粒子 Canvas**（独立 RAF 循环）：9 种粒子随主题切换——飘动的风、上升萤火、漂浮泡泡、雨幕+偶发闪电、缓落雪花、上升火星、迷雾、星辉闪烁

### 仪式感游戏结束页
- 弹出全屏模态：列出本局咒语 + 完整诗篇（每段标注触发的字，共鸣段高亮）
- 「复制故事」按钮 +「再玩一次」

### 响应式与可访问性
- 桌面双栏（棋盘 + 故事卷轴 / 咒语书侧栏），移动端单栏自适应
- Footer 桌面短页贴底、移动端长页自然下推
- 语义化 HTML + ARIA 标签

| 层 | 技术 |

## API 说明

### POST /api/story

LLM 故事续写。

```jsonc
// 请求
{
  "collectedWords": ["风", "夜"],
  "newWord": "梦",
  "currentStory": "已有故事全文...",
  "resonance": false
}

// 响应
{ "text": "夜幕降临，你流动的世界凝固成星河。" }
```

System prompt 要求模型以第二人称、诗意克制的笔触，每次续写 1-2 句，自然融入新字意象；共鸣时写一句转折句。

### POST /api/scene

氛围图生成（带内存缓存）。

```jsonc
// 请求
{ "theme": "night" }

// 响应
{ "image": "data:image/png;base64,...", "cached": false, "theme": "night" }
```

内部用字库的 `keywords` 拼成 `Atmospheric top-down game board background, {keywords}, dark vignette edges, cinematic, ...` 调图像生成模型。同 theme 二次命中直接返回缓存。

## 游戏机制说明

### 共鸣判定
玩家吃下的每个字带 `theme` 字段。若新字主题与上一个相同，`combo + 1`；当 `combo >= 1` 时共鸣激活。换异主题字则 combo 归零。

### 得分计算
```
实际得分 = 字的基础分 × (共鸣激活 ? 2 : 1)
```
稀有字（rarity 3）基础分 60，共鸣时单次可得 120。

### 速度递增
每吃一个字，tick 间隔减少 5ms，最低 80ms，让难度随局次递增。

## 玩法提示

- **共鸣是高分关键**：连续朝同主题的字吃两个，分数翻倍
- **稀有字值得追**：「光」「轮回」单字 60 分，共鸣可达 120
- **氛围切换即策略**：不同主题切换粒子与配色，可借此规划路径
- **故事是奖励**：不必追求极限分数，慢慢吃字也能收获一篇好诗

## 开发备注

- z-ai-web-dev-sdk **仅在后端** route handler 中使用，前端通过 `fetch` 调用 `/api/*`
- 游戏循环用 `setInterval` + refs 实现，避免闭包陈旧值；渲染用独立 `requestAnimationFrame` 保证咒文脉动平滑
- 氛围图加载期间画布带主题色脉冲边框 + 「氛围生成中」状态芯片
- 故事段、咒语书、模态均使用 `fancy-scroll` 自定义滚动条样式
